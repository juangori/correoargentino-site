Preguntas Frecuentes

Todo lo que necesitas saber sobre Correo Argentino Pro

Qué servicios de Correo Argentino soporta?

Soporta MiCorreo (para PyMEs y monotributistas, con cotización) y Paq.Ar v2 (para empresas con acuerdo comercial, con etiquetas). Leer más →

Necesito tener cuenta en Correo Argentino?

Sí. Necesitas una cuenta en MiCorreo o un acuerdo comercial Paq.Ar. El plugin se conecta a tu cuenta existente.

La licencia es por sitio?

Sí, cada licencia anual es válida para 1 dominio. Podés desactivarla y moverla a otro sitio cuándo quieras.

Cuánto dura la licencia?

La licencia tiene una vigencia de 1 año. Incluye actualizaciones y soporte durante ese periodo. Al vencer, podés renovarla para seguir recibiendo actualizaciones y soporte.

Qué pasa cuándo vence la licencia?

El plugin deja de funcionar (cotizar, crear envíos, generar etiquetas). Desde el panel del plugin vas a ver un aviso con el link para renovarla.

Incluye actualizaciones?

Sí, mientras tu licencia esté activa. Las actualizaciones llegan directamente a tu WordPress, como cualquier plugin del repositorio oficial.

Es compatible con mi tema?

El plugin funciona con cualquier tema compatible con WooCommerce. Soporta HPOS y el checkout por bloques. Ver guía de integración →

Cómo recibo la licencia?

Después de pagar con Mercado Pago, tu clave de licencia aparece en pantalla y se envía a tu email. La activación es instantánea.

Puedo usar el plugin en más de un sitio?

Cada licencia es para 1 sitio. Si necesitas usarlo en múltiples sitios, podés comprar licencias adicionales.

Qué pasa si cambio de dominio?

Podés desactivar la licencia en el sitio actual y activarla en el nuevo dominio desde el panel del plugin.

Funciona con el checkout por bloques?

Sí. El plugin es totalmente compatible con el nuevo checkout por bloques de WooCommerce, además del checkout clásico. Ver guía WooCommerce →

El seguimiento automático funciona con MiCorreo?

El seguimiento automático dentro de WooCommerce funciona con Paq.Ar. Con MiCorreo la API solo permite importar el envío: el pedido queda en "Importado" y el número de seguimiento, la etiqueta y los estados posteriores se gestionan en el panel de MiCorreo, después de cotizar y pagar el envío. Es una limitación de la API de Correo Argentino, no del plugin. Ver detalle →

Qué versión de WooCommerce necesito?

Se requiere WooCommerce 6.0 o superior. Recomendamos siempre usar la última versión disponible.
